## Published Description Summary

The page presents Solar System Simulation as a polished educational Unity
experience featuring the Sun, all eight planets, seven major moons,
deterministic analytical orbits, body-focused inspection, scientific
information panels, and a five-chapter cinematic tour.

It clearly states that:

- the simulation is an educational visualization rather than a date-exact
  ephemeris;
- planetary radii preserve exact Earth-relative mean-radius ratios;
- default orbital spacing is compressed for readability;
- `C` opens the guided physical-scale comparison;
- keyboard and mouse are required; and
- the macOS build is unsigned, unnotarized, and untested on macOS.

The published feature list includes verified celestial data, deterministic
Kepler motion, the complete approved body roster, exploration and learning
controls, layered rendering, pooled comets, audio, persistent settings,
responsive UI, reduced motion, Help, Credits, and source disclosures.

## Published Controls

- Move: `WASD` or arrow keys
- Focus: `F`
- Zoom: mouse wheel
- Pause: `Space`
- Navigator: `N`
- Tour: `T`
- Scale comparison: `C`
- Help: `H`

The in-project Help and controls reference remain authoritative for the complete
control set.
