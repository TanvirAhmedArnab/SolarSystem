## Known Limitations

- The simulation is an educational deterministic mean-orbit visualization, not
  a date-exact astronomical ephemeris.
- Default orbital spacing is compressed for readability.
- Keyboard and mouse are the supported input devices.
- The included comet fly-throughs are illustrative, not propagated scientific
  comet trajectories.
- The macOS Universal archive is unsigned, unnotarized, and not runtime-tested
  on macOS.

## Release Completion Decision

Solar System Simulation v1.0.0 satisfies the approved assignment and portfolio
publication scope. The project is released and may move to maintenance mode.
Future content, platform signing, portfolio video, case-study work, or feature
expansion is optional and must begin as a separately approved scope.
